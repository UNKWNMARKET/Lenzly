# LENZLY

A modern photography platform — Instagram for photographers, built with React + TypeScript + Tailwind CSS.

## Features
- **Feed** — photo-focused social feed with AI-discovered location spots
- **Explore** — filterable photo grid + AI photo spot map
- **Find a Photographer** — live map + list with filters (specialty, 2nd shooter, verified)
- **Profile** — photographer portfolio with Instagram/portfolio links, Pro upgrade
- **For Brands** — brand portal for hiring freelance photographers

## Setup

1. Install [Node.js](https://nodejs.org) (v18 or newer)
2. Open terminal in this folder and run:

```bash
npm install
npm run dev
```

3. Open `http://localhost:5173` in your browser

## Build for production

```bash
npm run build
npm run preview
```

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Wouter (routing)
- React-Leaflet (map)
- Lucide React (icons)
- Sonner (toast notifications)
